What an agency looks after on a client's behalf, and the four services it reads that from: the registrar, the DNS zone, the monitor and the site itself.

128 endpoints across 7 groups. A permission written `module.resource.action:own` is scoped: `:own` covers rows that are yours, `:any` covers everyone's, and `:any` satisfies a check for `:own`.
