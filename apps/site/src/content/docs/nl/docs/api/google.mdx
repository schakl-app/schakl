30 endpoints, verdeeld over 1 groep. Een recht geschreven als `module.resource.action:own` heeft een bereik: `:own` dekt rijen die van jou zijn, `:any` die van iedereen, en `:any` voldoet aan een controle op `:own`.

#### `GET /api/v1/google/calendar/calendars`

**Calendar List** — The viewer's own calendarList — the selection UI's read (#440). Briefly cached; the existing ``calendar.events`` scope covers it, so no re-consent is needed.

Recht: `google.connection.manage`

Antwoord: `200` · `CalendarListEntry[]`

#### `PUT /api/v1/google/calendar/calendars`

**Set Calendar Selection** — Choose which shared calendars sync for the viewer. Deselecting removes the calendar's cached events on the spot; selecting queues a sync so the agenda fills without waiting.

Recht: `google.connection.manage`

Request body: `CalendarSelection`

Antwoord: `200` · `CalendarListEntry[]`

#### `GET /api/v1/google/calendar/channels`

**Calendar Channels** — The viewer's selection off the database alone — what the Agenda's feeds menu reads on every open, so it never costs a Google call.

Recht: `google.calendar.read`

Antwoord: `200` · `SelectedCalendar[]`

#### `GET /api/v1/google/calendar/events`
