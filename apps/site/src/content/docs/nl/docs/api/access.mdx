Wie er mag inloggen, wat diegene daarna mag, welke klanten diegene ziet, en de sleutels waarmee een script namens hen handelt.

61 endpoints, verdeeld over 8 groepen. Een recht geschreven als `module.resource.action:own` heeft een bereik: `:own` dekt rijen die van jou zijn, `:any` die van iedereen, en `:any` voldoet aan een controle op `:own`.
